1) Crear la Hoja (Sheet) en Google Sheets

  1. Abre Google Drive y crea una hoja:
    — Español: Nuevo > Hojas de cálculo de Google
    — English: New > Google Sheets
  2. Renómbrala a Leads:
    — Español: Archivo > Cambiar nombre
    — English: File > Rename
  3. En la primera fila (A1..L1), escribe estos encabezados exactamente en este orden:
    Timestamp | Name | Company | Email | Phone | Project Type | Budget | Timeline | Location | Description | Questions | How Heard

    Nota: Los encabezados son solo etiquetas visuales. El script escribe por posición (appendRow), por lo que importa el orden de columnas.

  4. Verifica el nombre de la pestaña (tab): debe ser Leads.
    — Español: clic derecho en la pestaña > Cambiar nombre
    — English: right‑click the sheet tab > Rename
  5. Obtén el SPREADSHEET_ID desde la URL:
    https://docs.google.com/spreadsheets/d/1dfsIlSTMfm6Xae6TVZ3XV0HgEI1d7phrTMuW8LleMMo/edit

2) Crear el Apps Script vinculado (Linked Apps Script)

  1. Desde la hoja, abre el editor de script:
    — Español: Extensiones > Apps Script
    — English: Extensions > Apps Script
  2. En el editor:
    • Elimina myFunction si existe.
    • Crea el archivo Code.gs si no existe: + New file > Script.
    • Pega el siguiente código y AJUSTA las constantes:
    const SHEET_ID = '1dfsIlSTMfm6Xae6TVZ3XV0HgEI1d7phrTMuW8LleMMo'; // tu hoja
const SHEET_NAME = 'Leads';                        // nombre exacto de la pestaña
const NOTIFY_EMAIL = 'constanza.andrade@connie-tech.com';      // correo de notificación (opcional)

function doPost(e) {
  try {
    // Acepta form-urlencoded (lo que envía tu sitio) y JSON (por si pruebas con Postman)
    let data = e.parameter || {};
    if ((!data || Object.keys(data).length === 0) && e.postData && e.postData.type === 'application/json') {
      data = JSON.parse(e.postData.contents || '{}');
    }

    const ss = SpreadsheetApp.openById(SHEET_ID);
    const sheet = ss.getSheetByName(SHEET_NAME) || ss.getActiveSheet();

    sheet.appendRow([
      new Date(),
      data.name || '',
      data.company || '',
      data.email || '',
      data.phone || '',
      data.type || '',
      data.budget || '',
      data.timeline || '',
      data.location || '',
      data.description || '',
      data.questions || '',
      data.ref || ''
    ]);

    if (NOTIFY_EMAIL) {
      const subject = 'New Connietech Lead';
      const body = Object.keys(data).map(k => `${k}: ${data[k]}`).join('\n');
      MailApp.sendEmail(NOTIFY_EMAIL, subject, body);
    }

    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: String(err) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

// Opcional: para herramientas que envíen OPTIONS
function doOptions() {
  return ContentService.createTextOutput('');
}

3) Desplegar como Web App (Deploy Web App)

  1. Haz clic en Implementar (Deploy) > Nueva implementación (New deployment).
  2. En Seleccionar tipo (Select type), elige Aplicación web (Web app).
  3. Rellena:
    • Descripción (Description): v1
    • Ejecutar como (Execute as): Yo (Me)
    • Quién tiene acceso (Who has access): Cualquiera (Anyone)
  4. Haz clic en Implementar (Deploy) y luego en Revisar permisos (Review permissions) para aceptar.
  5. Copia la URL que termina en /exec. Esta será tu endpoint público.
  6. Para Connietech, el endpoint actual es:
    https://script.google.com/macros/s/AKfycbygdotVjIcoPyAbjPYh2SXmF05Lv-u32GmdbL-qArnm94p_R_89VMmA2dtILCDLOCQO2g/exec

6) Solución de problemas (Troubleshooting)

  • "No se encontró la función doPost" (Script function doPost not found): estás usando un despliegue antiguo sin doPost. Haz Deploy > New deployment y usa la NUEVA URL /exec.
  • 403/401 o pide iniciar sesión: Who has access no está en Anyone o estás usando /dev. Vuelve a desplegar y usa /exec.
  • No se insertan filas: SHEET_ID o SHEET_NAME incorrectos. Verifica el ID (empieza con "1...") y que la pestaña se llame exactamente Leads.
  • No llega el correo: revisa NOTIFY_EMAIL, carpeta Spam y límites de MailApp.
  • CORS: Apps Script no permite añadir headers CORS con ContentService; por eso el sitio usa fetch con mode:'no-cors' y no lee la respuesta. El envío llega igualmente.
